# Rendered prototype evidence

Captured in installed Google Chrome on November 25, 2026 (Los Angeles), using the production Next.js build and fictional Milo. Desktop: 1280 × 720 viewport; mobile: 390 × 844 emulation (not a physical iOS device). Full-page captures, with finite animations completed before capture.

- `desktop-landing.png`: landing page and fictional profiles.
- `desktop-dashboard.png`: initial simulated recommendation set.
- `desktop-adapted.png`: subsequent gentler selection after enjoyed + struggled feedback.
- `mobile-dashboard.png`: responsive caregiver view.

All selection is labeled simulated. These screenshots are UI evidence, not Gemini, clinical, engagement, or professional-review evidence. Automated accessibility checks passed on landing/dashboard/dialog in the tested Chromium environment; they do not establish full accessibility conformance.
